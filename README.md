# Sales Performance Dashboard (Excel Data Analysis Project)

## Project Objective
The objective of this project is to analyze sales performance data across major Indian cities to identify revenue trends, top-performing products, and business growth opportunities. This dashboard helps businesses monitor KPIs, improve strategic decision-making, and optimize sales operations using Microsoft Excel.

## About the Project
This project provides a complete Excel-based sales dashboard designed to answer key business questions and visualize performance metrics effectively.

### Questions Solved:
1. Which city generated the highest revenue?
2. Which product category performed best?
3. What are the monthly revenue trends?
4. Which locations need sales improvement?
5. How can product strategy be optimized?

---

## Key Performance Indicators (KPIs)
- Total Revenue
- Total Units Sold
- Top Performing City
- Best Selling Product
- Monthly Revenue Growth
- Product Revenue Contribution
- Sales Trend Analysis
- City-wise Revenue Comparison
